# JChatMind Universe Brain — 星空大脑可视化系统

> **Product Design Document**  
> 将 AI 后台推理过程转化为沉浸式宇宙剧场

---

## 1. 产品概述

### 1.1 一句话定义

一个全屏独立页面，用三维星空宇宙隐喻 AI 的推理大脑，将原本隐藏在后台的 Thinking → Tool Calling → Database Query → Response Generation 过程，转化为**可见、可感知、有叙事节奏**的宇宙事件。

### 1.2 用户场景

| 场景 | 用户行为 | 星空反应 |
|---|---|---|
| 日常问答 | 用户在聊天页输入问题 | `/universe` 页面实时同步：问题彗星射入 → 解析行星捕获 → 思考星环旋转 → 工具行星激活 → 数据回流 → 答案恒星爆发 |
| 回顾演示 | 用户打开 Universe 页面回顾某次对话 | 播放该对话的"星空录像"，可暂停、快进、拖拽进度条 |
| 被动观赏 | 用户将 Universe 页面投到副屏/大屏 | 像鱼缸/屏保一样，当有对话时自动上演宇宙剧场 |

### 1.3 核心体验原则

1. **延迟美学** — 不要求与前台毫秒同步，允许 300-800ms 的叙事性延迟，让动画有"起承转合"
2. **幽默陪伴** — 状态文字不是技术日志，而是有性格的"宇宙旁白"
3. **可阅读性** — 宇宙是装饰层，底层必须有清晰的信息架构，新用户 10 秒能看懂
4. **性能友好** — 60fps 在 2022 年后的笔记本上流畅运行

## 2. 视觉设计系统

### 2.1 色彩体系

基于现有 JChatMind 的赛博朋克暗色主题扩展：

```
宇宙背景        #03030A  (接近纯黑，带极微弱的蓝紫星云)
深空层次        #0A0A1A  (用于 UI 面板、HUD 背景)
核心恒星        #FFD700  → #FF6B35 渐变 (金黄到橙红，AI 心脏)
思考星环        #00D4AA  (青色，代表思维流动)
工具行星        #00B4FF  (亮蓝，代表工具调用)
记忆行星        #C084FC  (紫色，代表向量数据库/记忆)
生成光芒        #FF3366  → #FF9966 渐变 (粉红到橙，答案诞生)
数据流光        #FFFFFF  核心 + 尾迹渐隐 (信息传递)
星轨常态        rgba(255,255,255,0.08) (几乎不可见)
星轨激活        rgba(0,212,170,0.6) + glow (流动亮起)
文字主色        #E2E8F0
文字次要        #94A3B8
幽默旁白        #FBBF24 (琥珀黄，区别于系统文字)
```

### 2.2 空间层次

画面分为 3 个空间层，视差滚动增强沉浸感：

| 层级 | 内容 | 运动特性 |
|---|---|---|
| **远景层** (z: -500) | 静态星空背景、缓慢漂移的星云 | 极慢速旋转，0.1°/s |
| **中景层** (z: 0) | 核心恒星、行星轨道系统 | 核心动画层，60fps 流畅运动 |
| **近景层** (z: +200) | HUD 面板、状态文字、控制按钮 | 轻微视差跟随鼠标 |

### 2.3 字体规范

```

行星标签    Inter                      14px     uppercase, letter-spacing: 0.05em
```

### 3.2 天体详细定义

#### 🌟 核心恒星 — "Solvo" (中央大脑)

- **位置**：画面正中央
- **视觉**：缓慢脉动的发光球体，表面有等离子体纹理流动
- **颜色**：金黄 → 橙红渐变，脉动时亮度变化 ±20%
- **常态动画**：呼吸式缩放 `scale(1) → scale(1.05) → scale(1)`，周期 4s
- **激活态**：当整体推理负载高时，脉动加速到 1.5s，颜色偏红，周围出现日冕爆发
- **幽默标签**：悬浮显示 "🧠 大脑核心" 或 "正在集中精神..."

#### 🪐 思考星环 — "Cogito Ring" (思维环)

- **位置**：环绕核心恒星，半径约 120px (相对 1080p)
- **视觉**：半透明圆环，由数百个微小光点组成
- **常态**：静态淡绿色圆环，光点微弱闪烁
- **思考态**：光点开始沿逆时针方向流动，速度随思考复杂度变化，环体亮度提升至 80%
- **深度思考**：出现多层同心环，类似土星环，外层环旋转更快
- **幽默标签**："💭 脑子开始转了..." → "🤯 脑子转得比风扇还快！"

#### 🔮 记忆行星 — "Memoria" (向量数据库)

- **位置**：左上方轨道，椭圆轨道，距中心 250px
- **视觉**：紫色水晶质感球体，表面有网格纹理（象征向量空间）
- **常态**：缓慢自转，表面网格微弱发光
- **查询态**：表面网格亮度剧增，向外发射搜索射线（细光束向四周探测），然后有几条光束收回（象征命中 chunk）
- **数据回流**：被命中的 chunk 化为小光点，沿星轨流向核心
- **大小变化**：查询到的相关 chunk 越多，行星体积越大（象征信息丰富度）
- **幽默标签**："🔮 翻记忆宫殿找资料..." → "📚 找到了 5 本武功秘籍！"

#### ⚙️ 工具行星 — "Instrumentum" (工具执行器)

- **位置**：右上方轨道，椭圆轨道，距中心 250px
- **视觉**：蓝色机械质感球体，表面有齿轮纹理
- **常态**：自转，齿轮纹理缓慢转动
- **调用态**：行星表面裂开/展开（机械变形），内部射出工具特定的图标光效：
  - `web_search` → 🔍 放大镜光束射向远方（屏幕外）
  - `code_executor` → 💻 代码瀑布流下
  - `file_reader` → 📄 文件图标飞出
  - `calculator` → 🔢 数字环绕
- **执行完成**：工具图标化为光点沿星轨返回
- **幽默标签**："🔧 掏出工具箱..." → "🌐 正在全网搜刮答案..."

#### 🧩 推理行星 — "Ratiocinatio" (推理链)

- **位置**：下方轨道，椭圆轨道，距中心 220px
- **视觉**：青色半透明球体，内部有分形几何结构
- **常态**：内部几何缓慢变形
- **推理态**：内部出现文字流（模糊的代码/推理步骤），分形结构快速迭代
- **多步推理**：每完成一步，球体表面多一圈光环，最多可叠加 5 圈
- **幽默标签**："🧩 正在拼逻辑拼图..." → "✨ 啊哈！拼上了！"

#### ☄️ 问题彗星 — "Quaestio" (用户问题)

- **位置**：从屏幕边缘随机角度射入
- **视觉**：拖着长尾的发光球体，尾迹带有问题文字的粒子消散效果
- **轨迹**：沿抛物线飞向核心恒星
- **到达时**：被核心恒星"吸收"，产生一次光爆，随后思考星环开始旋转
- **幽默标签**：随彗星飞行显示用户问题的摘要（前 15 字）

#### ✨ 答案光束 — "Responsum" (生成答案)

- **位置**：从核心恒星射向屏幕边缘（象征输出到前台）
- **视觉**：粗壮的渐变光束，从核心向边缘扩散，沿途洒落光尘粒子
- **生成进度**：光束长度随生成进度从 0% → 100%
- **完成时**：光束末端绽放一次烟花效果，然后渐隐
- **幽默标签**："✍️ 正在奋笔疾书..." → "🎉 好了！拿去不谢！"

### 3.3 星轨系统

- **常态**：极细半透明线，几乎融入背景
- **激活**：当两个天体之间有数据流动时，对应轨道段亮起：
  - 亮起方式：从源天体开始，一道亮光沿轨道向目标天体流动
  - 光斑宽度：约 4-8px，带发光外晕
  - 颜色：取决于数据类型（查询=紫色，工具调用=蓝色，推理=青色，答案=粉橙）
  - 尾迹：光斑后方有 20% 透明度的渐隐尾迹，长度约 100px
  - 多数据并发：同一条轨道上可同时有多个光斑向不同方向流动

## 4. 叙事流程 — SSE 事件到宇宙剧场

### 4.1 事件映射表

| 前台 SSE 事件 | Universe 宇宙事件 | 持续时间 | 幽默旁白 |
|---|---|---|---|
| `USER_MESSAGE` (用户发送消息) | ☄️ 问题彗星从边缘射入，飞向核心 | 1.5s | "🚀 收到一个宇宙级难题！" |
| `AI_PLANNING` (AI 开始规划) | 🌟 核心恒星脉动加速，思考星环开始旋转 | 持续至下一阶段 | "🗺️ 大脑正在画作战地图..." |
| `AI_THINKING` (AI 思考中) | 🧩 推理行星激活，内部出现逻辑流 | 持续 | "💭 进入深度思考模式..." |
| `RETRIEVAL_START` (开始检索) | 🔮 记忆行星发射搜索射线 | 0.5s | "🔍 翻箱倒柜找记忆中..." |
| `RETRIEVAL_RESULT` (检索结果) | 🔮 射线收回，行星变大，光点沿轨流向核心 | 1s | "📦 找到 {n} 块记忆碎片！" |
| `TOOL_CALL_START` (工具调用) | ⚙️ 工具行星展开，射出工具图标 | 0.5s | "🔧 召唤 {tool_name} 神器！" |
| `TOOL_CALL_RESULT` (工具结果) | ⚙️ 图标化为光点返回，沿轨流向核心 | 1s | "📊 {tool_name} 满载而归！" |
| `AI_STREAMING_CHUNK` (生成中) | ✨ 答案光束从核心射出，逐渐延伸 | 持续 | "✍️ 正在把想法翻译成人类语言..." |
| `AI_DONE` (完成) | ✨ 光束到达边缘绽放烟花，所有天体进入"满足态"缓慢脉动 | 2s | "🎉 大功告成！脑细胞可以下班了~" |
| `ERROR` (出错) | 💥 核心恒星闪烁红光，出现裂纹效果，幽默错误提示 | 3s | "😵 大脑短路了... 正在重启中..." |

## 6. 动画规范

### 6.1 缓动函数定义

```typescript
// 宇宙动画专用缓动
const EASINGS = {
  // 彗星射入 — 先快后慢，有冲击感
  cometEnter:   [0.25, 0.46, 0.45, 0.94],  // ease-out-quad
  
  // 光爆 — 瞬间到达峰值然后衰减
  burst:        [0.16, 1, 0.3, 1],          // ease-out-expo
  
  // 星轨流动 — 匀速但有轻微加速感
  flow:         [0.4, 0, 0.2, 1],           // ease-in-out
  
  // 行星展开 — 弹性机械感
  planetary:    [0.68, -0.55, 0.265, 1.55], // spring-ish
  
  // 旁白弹跳 — 俏皮感
  bounceText:   [0.175, 0.885, 0.32, 1.275], // bounce
  
  // 脉动 — 正弦波
```

## 9. 技术选型建议

### 9.1 推荐方案：Canvas 2D + Framer Motion（混合架构）

**为什么不是纯 Three.js？**
- 2D 伪 3D 足以实现设计效果，性能更好
- 移动端兼容性更强
- 与现有 framer-motion 生态兼容
- 开发速度更快

**架构分层**：

```
Layer 1: HTML/CSS (Framer Motion)
  ├── HUD 面板（对话框、时间线、数据面板、按钮）
  ├── 行星标签文字
  └── 幽默旁白文字

Layer 2: Canvas 2D (自定义渲染循环, 60fps)
  ├── 星空背景粒子
  ├── 星轨线条
  ├── 核心恒星
  ├── 行星球体（伪 3D 用渐变+阴影模拟）
  ├── 数据流光斑
  ├── 彗星尾迹
  └── 烟花粒子

Layer 3: Offscreen Canvas (可选优化)
  └── 预渲染静态元素（背景星空）
```

### 9.2 核心库选择

| 用途 | 库 | 理由 |
|---|---|---|
| 动画编排 | **Framer Motion** | 已安装，用于 UI 层动画 |
| Canvas 渲染 | **原生 Canvas 2D API** | 足够，无需额外依赖 |
| 轨道计算 | **自定义数学** | 椭圆轨道公式简单，无需物理引擎 |
| 粒子系统 | **自定义** | 需求简单，1500 粒子原生 Canvas 可轻松处理 |
| 状态共享 | **React Context** | 与现有架构一致 |
| 音效（可选 V2） | **Web Audio API** | 原生支持，无需库 |

### 9.3 性能预算

```
目标：60fps @ 1920x1080 on MacBook Air M1 / Windows 11 + Chrome

Canvas 2D 性能估算：
- 背景粒子 1200 个：~0.3ms/frame
- 星轨 8 条：~0.1ms/frame
- 行星 4 个 + 核心 1 个：~0.5ms/frame
- 数据流光斑 10 个：~0.2ms/frame
- 粒子效果 100 个：~0.3ms/frame
- 总计：~1.4ms/frame（远低于 16.6ms 预算）

优化策略：
- 背景星空用 Offscreen Canvas 预渲染，每 5 帧更新一次
- 粒子对象池复用，避免 GC
- 视口外元素不渲染
- 移动端自动降低粒子数量到 600
```

## 附录 A：轨道数学公式

```typescript
// 椭圆轨道参数方程
function getOrbitPosition(
  centerX: number,
  centerY: number,
  semiMajor: number,      // 长半轴
  semiMinor: number,      // 短半轴
  angle: number,          // 当前角度 (0-2π)
  tilt: number = 0        // 轨道倾斜角 (模拟 3D 透视)
): { x: number; y: number; z: number } {
  const x = semiMajor * Math.cos(angle);
  const y = semiMinor * Math.sin(angle) * Math.cos(tilt);
  const z = semiMinor * Math.sin(angle) * Math.sin(tilt);
  
  return {
    x: centerX + x,
    y: centerY + y,
    z: z, // 用于透视缩放: scale = fov / (fov + z)
  };
}

// 透视投影
function project3D(x: number, y: number, z: number, fov: number = 800): {
  screenX: number;
  screenY: number;
  scale: number;
} {
  const scale = fov / (fov + z);
  return {
    screenX: x * scale,
    screenY: y * scale,
    scale,
  };
}
```

## 附录 B：伪 3D 球体绘制

```typescript
// Canvas 2D 绘制伪 3D 行星
function drawPlanet(
  ctx: CanvasRenderingContext2D,
  x: number, y: number,
  radius: number,
  baseColor: string,
  glowColor: string,
  rotation: number
) {
  // 外发光
  const glow = ctx.createRadialGradient(x, y, radius * 0.8, x, y, radius * 2);
  glow.addColorStop(0, glowColor + '40'); // 25% opacity
  glow.addColorStop(1, glowColor + '00'); // 0% opacity
  ctx.fillStyle = glow;
  ctx.beginPath();
  ctx.arc(x, y, radius * 2, 0, Math.PI * 2);
  ctx.fill();
  
  // 主球体 — 径向渐变模拟光照
  const sphere = ctx.createRadialGradient(
    x - radius * 0.3, y - radius * 0.3, radius * 0.1, // 高光偏移
    x, y, radius
  );
  sphere.addColorStop(0, lighten(baseColor, 40));
  sphere.addColorStop(0.5, baseColor);
  sphere.addColorStop(1, darken(baseColor, 30));
  
  ctx.fillStyle = sphere;
  ctx.beginPath();
  ctx.arc(x, y, radius, 0, Math.PI * 2);
  ctx.fill();
}
```

## 二、材质参数详解

### 1. 磨砂拉丝不锈钢 (加班星)
```typescript
{
  roughness: 0.6,    // 较高粗糙度 → 哑光感
  metalness: 0.9,    // 高金属度 → 强烈反光
  clearcoat: 0,      // 无清漆层
}
```
**视觉效果**：像被盘包浆的机械零件，有细微的划痕纹理感。

### 2. 青瓷釉面 (摸鱼星)
```typescript
{
  roughness: 0.15,   // 低粗糙度 → 光滑釉面
  metalness: 0.0,    // 非金属 → 陶瓷质感
  clearcoat: 0.8,    // 厚清漆层 → 釉面反光
  clearcoatRoughness: 0.2,
}
```
**视觉效果**：像景德镇青瓷，表面有一层温润的釉光。

### 3. 紫铜锻打 (咖啡星)
```typescript
{
  roughness: 0.3,    // 中等粗糙度
  metalness: 1.0,    // 全金属 → 铜的红褐色光泽
}
```
**视觉效果**：像手冲咖啡壶的铜质表面，温暖的红褐色金属反光。

### 4. 水晶玻璃 (Bug 星)
```typescript
{
  roughness: 0.0,    // 完全光滑
  metalness: 0.1,    // 微弱金属感
  transparent: true, // 透明
  opacity: 0.75,     // 75% 不透明度
  transmission: 0.6, // 透光率
  thickness: 0.5,    // 玻璃厚度
  ior: 1.5,          // 折射率 (标准玻璃)
  clearcoat: 1,      // 表面清漆
}
```
**视觉效果**：像红色水晶球，可以透视内部，边缘有折射高光。

### 5. 黑胡桃木纹 (脱发星)
```typescript
{
  roughness: 0.9,    // 高粗糙度 → 木头质感
  metalness: 0.0,    // 非金属
}
```
**视觉效果**：像高档书桌的木纹表面，温暖朴实。使用程序化的颜色渐变模拟木纹方向感。

### 6. 高温珐琅 (福报星)
```typescript
{
  roughness: 0.1,    // 极低粗糙度 → 镜面般光滑
  metalness: 0.3,    // 微弱金属基底
  emissive: '#FFD700',      // 自发光
  emissiveIntensity: 0.15,  // 微光
  clearcoat: 1,      // 完美清漆
  clearcoatRoughness: 0.05,
}
```
**视觉效果**：像景泰蓝的珐琅表面，金光闪闪，带有微弱的自发光。

### 7. 镜面金属 (KPI 星)
```typescript
{
  roughness: 0.2,    // 低粗糙度
  metalness: 1.0,    // 全金属
}
```
**视觉效果**：像不锈钢镜面，冷峻的银白色反光。

### 8. 黑曜石抛光 (Deadline)
```typescript
{
  roughness: 0.05,   // 极低粗糙度 → 镜面抛光
  metalness: 1.0,    // 全金属
}
```
**视觉效果**：像抛光的黑曜石或钢琴烤漆，能清晰反射周围环境。

## 三、运动参数

### 轨道运动公式
```typescript
// 每帧更新
angle += speed * timeSpeed * delta * 0.3;
position.x = cos(angle) * distance;
position.z = sin(angle) * distance;
```

| 参数 | 含义 | 默认值 |
|---|---|---|
| `speed` | 天体基础角速度 (rad/s) | 0.25 ~ 2.5 |
| `timeSpeed` | 用户调节的时间倍速 | 0 / 0.5 / 1 / 2 / 5 |
| `delta` | 帧间隔时间 (秒) | ~0.016 (60fps) |
| `0.3` | 全局减速系数 | 让运动更优雅 |

### 各天体周期（timeSpeed = 1x 时）

| 天体 | 周期（秒/圈） | 特性 |
|---|---|---|
| 加班星 | ~8.4s | 最快，社畜永动机 |
| Deadline | ~11.6s | 第二快，永远在逼近 |
| Bug 星 | ~17.5s | 中等，出没无常 |
| 咖啡星 | ~26.2s | 稳定供能 |
| KPI 星 | ~34.9s | 冷酷精确 |
| 脱发星 | ~41.9s | 缓慢但坚定 |
| 摸鱼星 | ~52.4s | 最慢，悠然自得 |
| 福报星 | ~83.8s | 最慢最大，终极boss |

## 四、环境组件参数

### 底座
- 直径：20 ~ 21 单位
- 高度：0.8 单位
- 材质：深木色 `#3D2B1F`，粗糙度 0.8

### 轨道环
- 管径：0.02 单位（极细金属丝）
- 材质：黄铜色 `#C9A961`，金属度 0.8

### 齿轮装饰
- 位置：轨道环两端
- 材质：古铜色 `#B8A88A`
- 动画：持续缓慢自转

### 台灯
- 位置：[-8, 5, -6]
- 光源：聚光灯，暖白色 `#FFF0D0`
- 角度：60°，半影 50%
- 强度：80

### 房间光照
- 环境光：40% 强度，暖白色 `#FFF5E6`
- 主方向光：模拟窗户光，`[10, 12, 8]`
- 补光：淡紫色，从反方向填充阴影

## 六、性能注意事项

### 渲染预算

```
目标：60fps @ 1920×1080

场景元素数量：
- 背景平面：1
- 底座几何体：~5 (主座 + 环 + 柱 + 铭牌)
- 轨道环：8
- 齿轮装饰：16
- 天体球体：8 (32×32 分段)
- 行星环：2 (福报星)
- 卫星：1
- 台灯组件：~6
- 灯光：5

多边形总数：~15,000 (极低)
绘制调用：~30-40

预估帧时间：~2-3ms (远低于 16.6ms 预算)
```

### 优化策略

1. **几何体简化**
   - 天体使用 32×32 分段球体（平衡质量和性能）
   - 轨道环使用 128 段（足够平滑）
   - 底座圆柱 64 段（近看不粗糙）

2. **材质优化**
   - 透明材质（玻璃）尽量减少重叠
   - 自发光材质仅在需要时使用
   - 清漆层（clearcoat）计算较贵，仅在 3 个天体上使用

3. **阴影优化**
   - 仅主方向光和台灯投射阴影
   - 阴影贴图 1024×1024（够用）
   - 阴影相机范围限制在场景范围内

4. **移动端适配**
   - 自动降低抗锯齿质量
   - 减少粒子/特效数量
   - 降低阴影分辨率
   - 限制最大缩放距离

5. **Three.js 特定优化**
   - 使用 `toneMapping: ACESFilmicToneMapping` 提升视觉质量
   - `antialias: true` 开启 MSAA
   - 合理设置 `far/near` 裁剪面避免精度问题

### 已知限制

- **包体积**：Three.js + R3F 增加约 ~600KB gzip 后的 JS
- **内存占用**：3D 纹理和几何体占用额外 GPU 内存 (~50-100MB)
- **低端设备**：2018 年前的手机可能出现卡顿，建议自动检测并降低质量

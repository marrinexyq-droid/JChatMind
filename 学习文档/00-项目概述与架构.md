# 00 — JChatMind 项目概述与架构

## 项目定位

JChatMind 是一个基于 **Spring AI + React** 的 **AI Agent 系统**，实现了 Think-Execute 自主决策循环。它不是简单的"调 API 聊天"，而是能自主规划、调用工具、检索知识库、多步推理的智能体系统。

## 核心设计模式

| 设计模式 | 使用位置 | 作用 |
|---------|---------|------|
| **注册表模式** | ChatClientRegistry | 用 Map\<String, ChatClient\> 管理多模型，按名称查找 |
| **工厂模式** | JChatMindFactory | 封装 Agent 的复杂构建过程（加载配置、恢复记忆、注册工具） |
| **外观模式** | *FacadeServiceImpl | 对 Controller 提供统一接口，隐藏底层 Mapper/Service 的复杂性 |
| **策略模式** | Tool 接口 + 多种实现 | 统一工具接口，不同工具不同策略，新增工具不修改核心代码 |
| **观察者模式** | ChatEvent + @EventListener | Controller 发布事件，Listener 异步消费，解耦调用方和处理方 |
| **状态机** | AgentState 枚举 | IDLE→THINKING→EXECUTING→FINISHED/ERROR |
| **DTO 模式** | Entity/DTO/VO/Request/Response | 每层有自己的数据模型，互不污染 |
| **转换器模式** | *Converter | 负责不同模型之间的转换（Entity ↔ DTO ↔ VO） |

## 请求全链路（最重要）

```
1. 用户在前端输入消息
2. POST /api/chat-messages {role:"user", content:"..."}
3. ChatMessageController.createChatMessage()
4. ChatMessageFacadeServiceImpl.createChatMessage()
   a. doCreateChatMessage() → 先持久化 UserMessage 到 DB
   b. publisher.publishEvent(new ChatEvent(agentId, sessionId, content))
5. Controller 返回 chatMessageId（HTTP 200）
6. @Async ChatEventListener.handle(ChatEvent)  — 在后台线程池执行
7. JChatMindFactory.create(agentId, chatSessionId)
   a. loadAgent() → 查 DB 获取 Agent 配置
   b. toAgentConfig() → 把 JSONB 字段反序列化为类型安全的 DTO
   c. loadMemory() → 恢复最近 N 条聊天记录为 Message 列表
   d. resolveRuntimeKnowledgeBases() → 查出关联的知识库
   e. resolveRuntimeTools() → 合并 FIXED + OPTIONAL 工具
   f. buildToolCallbacks() → 转换为 Spring AI 的 ToolCallback
   g. buildAgentRuntime() → 构造 JChatMind 实例
8. JChatMind.run() → Think-Execute 循环
   a. step() → think() → execute() → 循环直到 FINISHED
   b. 每次产生消息 → saveMessage(持久化DB) + refreshPendingMessages(SSE推送)
9. 前端 SSE 收到消息 → 渲染到聊天界面
```

## 为什么这个项目有竞争力（面试用）

**对比"调 API 聊天"项目的区别：**

| 维度 | 普通聊天项目 | JChatMind |
|------|------------|-----------|
| 交互模式 | 一问一答 | 多步推理循环（Think-Execute） |
| 工具调用 | 无 / if-else 硬编码 | 框架化：FIXED+OPTIONAL，新增0侵入 |
| 知识库 | 无 | 完整的 RAG 链路：解析→分块→嵌入→向量检索 |
| 模型选择 | 硬编码一个模型 | 注册表模式，动态切换 |
| 实时反馈 | 等待完整回复 | SSE 实时推送 Agent 执行状态 |
| 状态管理 | 无 | 状态机驱动 |
| 消息持久化 | 无 | 全量持久化 + 滑动窗口恢复 |

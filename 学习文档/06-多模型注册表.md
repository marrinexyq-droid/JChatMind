# 06 — 多模型注册表模式

> 相关文件：`MultiChatClientConfig.java`, `ChatClientRegistry.java`, `AgentDTO.java`

---

## 一、设计意图

支持 DeepSeek 和智谱 AI 两种模型，Agent 可以按需切换，新增模型不需要修改核心代码。

## 二、实现方式

### 2.1 注册多个 ChatClient Bean

```java
@Configuration
public class MultiChatClientConfig {

    // Bean 名称为 "deepseek-chat"
    @Bean("deepseek-chat")
    public ChatClient deepSeekChatClient(DeepSeekChatModel deepSeekChatModel) {
        return ChatClient.create(deepSeekChatModel);
    }

    // Bean 名称为 "glm-4.6"
    @Bean("glm-4.6")
    public ChatClient zhiPuAiChatClient(ZhiPuAiChatModel zhiPuAiChatModel) {
        return ChatClient.create(zhiPuAiChatModel);
    }
}
```

### 2.2 注册表：ChatClientRegistry

```java
@Component
public class ChatClientRegistry {

    // ⭐ Spring 自动注入所有 ChatClient Bean → Map
    // key = Bean 名称 ("deepseek-chat", "glm-4.6")
    // value = ChatClient 实例
    private final Map<String, ChatClient> chatClients;

    public ChatClientRegistry(Map<String, ChatClient> chatClients) {
        this.chatClients = chatClients;
    }

    // 按名称查找
    public ChatClient get(String key) {
        return chatClients.get(key);
    }
}
```

**Spring 自动注入 Map 的原理**：
当一个 Bean（ChatClientRegistry）的构造函数参数是 `Map<String, ChatClient>` 时，Spring 会自动查找容器中所有 `ChatClient` 类型的 Bean，以 Bean 名称作为 key，Bean 实例作为 value，组装成一个 Map 注入。这就是注册表模式的"自动注册"机制。

### 2.3 使用方式

```java
// JChatMindFactory.buildAgentRuntime()
ChatClient chatClient = chatClientRegistry.get(agent.getModel());
// agent.getModel() = "deepseek-chat" 或 "glm-4.6"
```

### 2.4 Agent 配置中的模型选择

```java
// AgentDTO.java
public enum ModelType {
    DEEPSEEK_CHAT("deepseek-chat"),
    GLM_4_6("glm-4.6");

    private final String modelName;

    public static ModelType fromModelName(String modelName) {
        for (ModelType type : values()) {
            if (type.modelName.equals(modelName)) {
                return type;
            }
        }
        throw new IllegalArgumentException("Unknown model type: " + modelName);
    }
}
```

Agent 的 `model` 字段在数据库存的是 `"deepseek-chat"` 字符串，通过 `fromModelName()` 转为枚举，再传到 `chatClientRegistry.get(model.getModelName())`。

## 三、配置驱动

### application.yaml

```yaml
spring:
  ai:
    deepseek:
      api-key: sk-xxx
      base-url: https://api.deepseek.com
      chat:
        options:
          model: deepseek-chat
    zhipuai:
      api-key: xxx.mOw9PJtTN3boYD7H
      base-url: https://open.bigmodel.cn/api/paas
      chat:
        options:
          model: glm-4.6
```

Spring AI 的 Starter 自动读取 `spring.ai.deepseek.*` 前缀的配置，创建 `DeepSeekChatModel` Bean。同理，`spring.ai.zhipuai.*` 创建 `ZhiPuAiChatModel` Bean。

## 四、新增一个模型的步骤

假设要接入通义千问（Qwen）：

**1. 添加 Maven 依赖**
```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-model-qwen</artifactId>
</dependency>
```

**2. 在 MultiChatClientConfig 注册新 Bean**
```java
@Bean("qwen-plus")
public ChatClient qwenChatClient(QwenChatModel qwenChatModel) {
    return ChatClient.create(qwenChatModel);
}
```

**3. 在 AgentDTO.ModelType 添加新枚举**
```java
public enum ModelType {
    DEEPSEEK_CHAT("deepseek-chat"),
    GLM_4_6("glm-4.6"),
    QWEN_PLUS("qwen-plus");  // ← 新增
}
```

**需要修改的文件**：只这 3 个文件。
**不需要修改的文件**：JChatMind、JChatMindFactory、ChatClientRegistry、所有 Service、所有 Controller → **0 修改**。

## 五、面试核心问题

### Q1: 注册表模式怎么实现的？

Spring 的 `@Bean("name")` + `Map<String, ChatClient>` 自动注入。

### Q2: 如果要加第三个模型要改哪些代码？

3 个文件：pom.xml（加依赖）、MultiChatClientConfig（注册 Bean）、AgentDTO.ModelType（加枚举）。

### Q3: 如果 Agent 配置了不存在的模型会怎样？

`chatClientRegistry.get("not-exist")` 返回 `null`，`JChatMindFactory.buildAgentRuntime()` 会抛 `IllegalStateException("未找到对应的 ChatClient")`。

# Title: 爱因斯坦-波多尔斯基-罗森佯谬与量子力学完备性争论
# Level: 2 (物理哲学与历史层)

1935年，阿尔伯特·爱因斯坦（Albert Einstein）、鲍里斯·波多尔斯基（Boris Podolsky）和内森·罗森（Nathan Rosen）发表了著名的 EPR 论文，向哥本哈根学派的量子力学诠释发起了严厉的哲学挑战。这场争论的核心不在于量子力学的数学计算是否正确（其统计预测已被广泛证实），而在于这套理论是否能够完整地描述客观世界。

# ------ 子切片嵌套 (Child Chunk) ------
# ID: doc_003_child_A
# Tags: [EPR_Paradox, Local_Realism, Hidden_Variables]
# Hypothetical_Questions: ["什么是EPR佯谬？", "定域实在论的两个核心假设是什么？", "爱因斯坦为什么认为量子力学是不完备的？"]

EPR 的推导过程牢固建立在两个直觉性的西方经典物理假设之上，即**定域实在论（Local Realism）**：
1. **定域性原理（Locality）**：在空间上处于类时隔离（Space-like separated）的两个系统 A 和 B，对 A 进行的任何局部测量或操作，绝不可能瞬间改变系统 B 的真实物理状态。
2. **实在论（Realism）**：如果无需干扰系统，我们就能以 100% 的准确度预测某个物理量的值，那么在客观世界中必然存在一个独立于观察者的“实在要素”（Element of Reality）对应着这个值。

在一对相互纠缠的粒子 A 和 B 中，EPR 发现通过测量 A 的动量 $p_A$，可以瞬间百分之百精确地预言 B 的动量 $p_B$。由于定域性，测量 A 没有干扰 B，因此 $p_B$ 的值在测量前就已经确定地存在于 B 中。量子力学波函数未能包含这些早已确定的物理量，爱因斯坦由此断言：量子力学是不完备的，必须引入未知的“隐变量（Hidden Variables）”来补全理论。
# ------ 子切片嵌套结束 ------

玻尔（Niels Bohr）随后发表了同名论文进行反驳，他认为 EPR 对“干扰”的定义过于经典。玻尔指出，测量手段与被测量系统之间存在不可分割的整体性，在对 A 进行测量时，整个系统的实验条件已经改变，因此不存在独立于测量安排的“物理实在”。

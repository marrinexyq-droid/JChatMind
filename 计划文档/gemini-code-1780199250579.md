# Title: 物理学诺贝尔奖成就：阿斯佩纠缠光子检测实验
# Level: 3 (实验物理层)

尽管贝尔不等式在数学上无懈可击，但在实验室中真正检验它却极其困难。早期的实验由于设备效率低下或实验设计缺陷，存在诸多“漏洞（Loopholes）”，使得坚持定域实在论的物理学家可以辩称不等式的违背是由实验误差导致的。1982年，阿兰·阿斯佩（Alain Aspect）在巴黎第十一大学完成了一项里程碑式的实验，首次在真正意义上挑战了定域隐变量理论。

# ID: doc_005_child_A
# Tags: [Aspect_Experiment, Locality_Loophole, Photonic_Entanglement]
# Hypothetical_Questions: ["阿斯佩实验是如何验证贝尔不等式的？", "什么是定域性漏洞？", "实验中为什么要用声光调制器？"]

阿斯佩实验的核心贡献在于尝试闭合了**“定域性漏洞（Locality Loopholes）”**。在先前的实验中，Alice 和 Bob 端的偏振测量方向是静态固定的。反对者认为，粒子在离开源头时，可能通过某种低于光速的未知未知经典信号“串通”了测量装置，从而模拟出了量子纠缠的效果。

为了杜绝这种可能性，Aspect 团队利用钙原子级联辐射产生的偏振纠缠光子对，将两端检测器的距离拉开至 12 米。最关键的是，他们在光子飞行途中（大约 40 纳秒的飞行窗口期内），引入了开关频率高达 50 MHz 的高频声光调制器（Acousto-optical Switches）。
该开关每隔 10 纳秒就随机在两个不同的偏振测量方向之间切换一次。由于方向的选择是在光子飞行途中“临时”做出的，Alice 端偏振器的改变若想以光速通知 Bob 端，至少需要 40 纳秒，此时 Bob 端的测量早已结束。

实验最终测得的 $S$ 参数为 $2.697 \pm 0.015$，在高达 **46 个标准差（$46\sigma$）**的绝对置信度下违背了经典贝尔不等式。这证实了即使在空间类时隔离下，非定域关联依然存在。
# ------ 子切片嵌套结束 ------

尽管 Aspect 实验极大地打击了定域隐变量论，但由于光子探测器的计数率较低，它依然留下了“探测效率漏洞（Detection Loophole）”。直到 2015 年，全球数个团队才完成了完美同时闭合所有核心漏洞的“无漏洞贝尔测试（Loophole-free Bell Test）”。

# Title: 复合量子系统的状态表示：贝尔态的数学形式与物理制备
# Level: 1 (基础理论层)

在双量子比特（Two-qubit）系统中，最著名的纠缠态是四个具有最大纠缠度的正交基底，被称为贝尔态（Bell States）或 EPR 对。当两个量子比特处于最大纠缠态时，系统的全局信息是完全确定的，但其局部子系统的信息却完全丢失。这意味着，如果你对其中任意一个比特进行局部测量，其结果完全是随机的（50% 概率为 0，50% 概率为 1）；然而，一旦两个比特的测量结果放在一起对比，就会发现它们之间存在着完美的、超越经典统计学的强关联。

# Hypothetical_Questions: ["什么是最大纠缠态？", "四个贝尔态的数学表达式是什么？", "如何通过量子线路制备贝尔态？"]

这四个贝尔态在计算基底 $\{|00\rangle, |01\rangle, |10\rangle, |11\rangle\}$ 下的标准数学表达式为：
$$|\Phi^{+}\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)$$
$$|\Phi^{-}\rangle = \frac{1}{\sqrt{2}}(|00\rangle - |11\rangle)$$
$$|\Psi^{+}\rangle = \frac{1}{\sqrt{2}}(|01\rangle + |10\rangle)$$
$$|\Psi^{-}\rangle = \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle)$$


*注（图表转义描述）：制备 $|\Phi^{+}\rangle$ 态的标准量子线路输入为两个处于基态的单比特 $|0\rangle_A$ 和 $|0\rangle_B$。首先使第一个量子比特 A 通过一个哈达玛门（Hadamard Gate, H），将其变为等权重叠加态 $\frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$；随后以 A 为控制比特，B 为目标比特，施加一个受控非门（CNOT Gate）。当 A 为 |1| 时，B 发生翻转，从而在输出端输出最大纠缠态。*
# ------ 子切片嵌套结束 ------

在实验实现中，这四种状态具有不同的宇称（Parity）和对称性特征。例如，$|\Psi^{-}\rangle$ 在单比特旋转下保持形式不变，被称为量子单态（Singlet State），在量子通信中具有极高的鲁棒性，是抵御集体退相干噪声的核心资源。

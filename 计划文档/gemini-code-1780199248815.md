在 EPR 佯谬提出后的近三十年里，定域隐变量理论与哥本哈根正统量子力学的争论一直被视为纯粹的哲学宿命论之争，因为两者在常规实验中的统计预测完全一致。直到 1964 年，约翰·贝尔（John Bell）发表了划时代的定理，指出定域隐变量理论在多方向关联测量下，其统计上限存在一个绝对的数学边界，而量子力学会突破这个边界。

# Hypothetical_Questions: ["什么是CHSH不等式？", "经典定域隐变量理论的相关性上限是多少？", "量子力学突破贝尔不等式的最大值是多少？"]

在实际实验中，最常用的贝尔不等式变形是由 Clauser, Horne, Shimony 和 Holt 提出的 CHSH 不等式。
假设 Alice 可以随机选择两个不同的偏振方向 $A$ 或 $A'$ 测量粒子 A，Bob 随机选择 $B$ 或 $B'$ 测量粒子 B。测量结果只能是 $+1$（透射）或 $-1$（吸收）。
基于定域实在论，粒子携带了隐变量 $\lambda$，各单项测量结果独立确定。根据代数恒等式 $A(B - B') + A'(B + B') = \pm 2$，对隐变量分布进行经典概率积分后，其关联期望值必须严格满足：
$$S_{classical} = |E(A, B) - E(A, B') + E(A', B) + E(A', B')| \le 2$$

然而，若两粒子处于最大纠缠单态 $|\Psi^{-}\rangle$，通过巧妙倾斜测量角度（如令 $A, B, A', B'$ 依次相差 $22.5^\circ$），量子力学算符给出的相关性计算结果将达到：
$$S_{quantum} = 2\sqrt{2} \approx 2.828$$
显然，$2\sqrt{2} > 2$。量子力学在数学上直接违背了经典定域实在论的不等式约束，这证明了两者在物理预言上是不相容的。
# ------ 子切片嵌套结束 ------

这个 $2\sqrt{2}$ 的上限被称为齐泽尔森界（Tsirelson's Bound），它是任何量子纠缠系统在双比特、双基底测量下所能达到的最大违背值。

# Title: 混合态的引入与复合系统纠缠度的定量测量
# Level: 2 (严格数学推导层)

当一个复合系统 $AB$ 处于纯态 $|\Psi_{AB}\rangle$ 时，我们可以通过其波函数完整描述。然而，在实际的物理环境中，系统不可避免地会受到外界噪声干扰，或者我们只能观测到其中一个子系统 $A$。此时，纯态波函数失效，我们必须引入密度矩阵（Density Matrix） $\rho_{AB}$ 来描述系统的混合状态。可分态的密度矩阵可以写成子系统密度矩阵的凸组合，而纠缠态则无法通过这种经典概率组合来表示。

# Tags: [Density_Matrix, Partial_Trace, Von_Neumann_Entropy]
# Hypothetical_Questions: ["如何用数学公式定量计算量子纠缠度？", "什么是部分迹和减少密度矩阵？", "冯诺依曼熵为0代表什么？"]

为了定量描述一个复合纯态系统 $AB$ 中子系统之间的纠缠程度，物理学上最普遍的方法是计算子系统的冯·诺依曼熵（Von Neumann Entropy），该度量也被称为纠缠熵（Entanglement Entropy）。
首先，通过对子系统 $B$ 的基底求部分迹（Partial Trace），“抹去”系统 $B$ 的经典信息，从而获取子系统 $A$ 的减少密度矩阵（Reduced Density Matrix）：
$$\rho_A = \text{Tr}_B(\rho_{AB}) = \text{Tr}_B(|\Psi_{AB}\rangle\langle\Psi_{AB}|)$$

随后，计算该减少密度矩阵 $\rho_A$ 的冯·诺依曼熵 $S(\rho_A)$：
$$S(\rho_A) = -\text{Tr}(\rho_A \log_2 \rho_A) = -\sum_{i} \lambda_i \log_2 \lambda_i$$
其中 $\lambda_i$ 是矩阵 $\rho_A$ 的非零特征值。
* 若 $S(\rho_A) = 0$，说明子系统 $A$ 依然处于纯态，系统 $AB$ 之间属于无纠缠的可分态。
* 若 $S(\rho_A) = \log_2 d$（$d$ 为子系统维度），则系统 $AB$ 处于最大纠缠态。
# ------ 子切片嵌套结束 ------

需要注意的是，纠缠熵仅在全局系统为**纯态**时才是完美的纠缠判据。如果全局系统本身就是包含经典热噪声的混合态，冯·诺依曼熵将同时包含经典不确定性和量子关联。此时需采用更复杂的工具，如同并发度（Concurrence）或负度（Negativity）。

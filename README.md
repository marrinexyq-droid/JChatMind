# JChatMind — AI 智能体助手

基于 [youngyangyang04/JChatMind](https://github.com/youngyangyang04/JChatMind) 的学习与实践 Fork，欢迎贡献。

## 技术栈

- Spring AI + Java 后端
- PostgreSQL + pgvector（RAG 知识库）
- DeepSeek / 智谱 AI 多模型支持
- SSE 实时通信
- Think-Execute Agent 循环
- React + TypeScript 前端

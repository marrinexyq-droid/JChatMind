# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to the label used in this repository.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for the reporter to provide more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Human implementation is required |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill refers to a canonical role, use the corresponding tracker label from this table.
